Astuce : remplissage automatique du navigateur

Pour que les formulaires se remplissent presque tout seuls, enregistrez une fois votre adresse dans le navigateur de la tablette :

  • Chrome : ⋮ → Paramètres → Adresses et autres → Ajouter une adresse.
  • Samsung Internet : ☰ → Paramètres → Données personnelles → Remplissage automatique.
  • Firefox : ⋮ → Paramètres → Adresses.

Ensuite, en touchant la case « Nom » d'un formulaire, le navigateur propose de tout remplir. Vous vérifiez, cochez le règlement et validez vous-même.
